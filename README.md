## 沪港 IPLC 是什么，适合谁用

IPLC 的全称是 International Private Leased Circuit（国际私有租用线路），它是物理隔离的点对点电路，数据不经过公网，也不与其他用户的流量混跑。和普通 VPS 走公网国际出口相比，IPLC 的优势集中在三点：延迟低且稳定、不受公网高峰拥堵影响、 IP 环境相对干净。

“沪港 IPLC”指的是上海入、香港出的这条专线方向。对用户来说它典型的用途包括：

- **跨境电商与独立站运营**：访问部署在香港的 ERP、店铺后台、素材库，要求登录环境稳定不跳验证；
- **跨境协同办公**：连香港的文件服务器、内网系统，偶发卡顿比绝对速度更影响体验；
- **长时间数据传输**：备份、同步、拉取香港节点上的服务，需要能持续跑的带宽而不是瞬时峰值。

一句话判断：如果你的业务出口在香港、人在华东，沪港 IPLC 是物理距离和延迟都比较优的方向；人在华南、出口也在香港，广港 IEPL 会更低延迟（端内 1~2ms 级别），沪港这条线的价值在于覆盖上海及周边用户。

## 哪些人适合买，哪些人该绕开

根据上面的配置和价格，沪港 IPLC（含 IXP）适合的人群比较清晰：

- **华东跨境卖家**：人在上海、江苏、浙江一带，业务后台部署在香港或对港有持续访问需求；
- **需要长期稳定香港出口的团队**：比如已经在用香港服务器部署 ERP、文件服务，希望登录环境稳定、不被公网波动打断；
- **已有国内云服务器、想降低跨境成本的 IXP 用户**：不想从头买独享 IPLC，用手头云厂资源串一条优化线路。

不太适合的情况同样明确：

- **人在华南的纯对港业务**：这条线路对你不是最优，广港 IEPL 延迟更低、可能价格更合适；
- **没有国内云服务器、预算又很紧的个人用户**：IXP 需要额外承担云服务器费用，独享 IPLC 起步 ¥650/月，都不是“便宜”的选择；
- **想拿这条线做机场或回国工具的人**：商家服务条款明确禁止这类用途，违者清退不退款。

## 常见问题

**沪港 IPLC 一个月最低多少钱？**

沪港 IPLC 共享带宽入门档 ¥288/月（1TB 流量、200M 峰值）；沪港 IXP 最低 ¥198/月（2TB 流量、500M 峰值，需自备云厂前置）；沪港 IPLC 独享带宽起步 ¥650/月（5Mbps、不限流量）。

**延迟真的能做到 21ms 吗？**

21ms 是商家公布的端内延迟，也就是从上海入口到香港出口这段专线内部的延迟，不包含你本地到入口的耗时，也不包含香港出口到目标平台的耗时。实际体验要结合你的宽带质量和目标平台位置综合判断，端内 21ms 只保证专线这一段不会成为主要瓶颈。

**1TB 流量够用吗？**

取决于你的业务类型。日常办公、ERP 访问、网页后台操作，1TB 一般够用；如果涉及大量文件同步、素材上传下载或视频推流，1TB 会比较紧。注意 MKCloud 的计量型套餐按上行+下行双向合计流量，实际可用的总传输量约为标称额度的一半，规划时要把这一点算进去。

**流量用完了怎么办？**

沪港 IPLC 共享带宽产品支持自助购买流量重置或提交工单补差价升级；沪港 IXP 产品是超量停机，需要等下一个计费周期恢复或自行升级套餐。

**支持退款吗？**

MKCloud 官方购物车页面和知识库都写明：仅支持质量问题退款，需要提交具体延迟、速度数据证明服务质量问题；服务开通后不支持更换到其他地域的产品。下单前先把业务需求确认清楚，减少开通后才发现选错线路的情况。

**优惠码可以直接叠加使用吗？**

目前的常规优惠码（MK-8.8 循环、MK-7.8 首月等）都有明确适用范围，比如 MK-8.8 适用于流量计费产品、MK-7.8 适用于独享带宽产品，活动期间是否可叠加、是否有专属产品不参与折扣，以商家下单页和活动页实时提示为准。沪港 IPLC 此前的 7.7 折循环 / 首月 5 折活动已结束，不要按历史折后价计算当前预算。
